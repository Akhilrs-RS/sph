# AuraStore & DropshipOS

A modern E-Commerce & Dropshipping Management Platform built with React (.jsx) and Tailwind CSS.

## Getting Started

The application is located in the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:3000` to view the platform.

For detailed documentation on features and architecture, see [frontend/README.md](frontend/README.md).
